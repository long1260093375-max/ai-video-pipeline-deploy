# 理解表规则（用户 2026-11-05 确认）

## 方向
以文案为优先：先从文案中提取关键信息，再做成图片。理解表是文案到图片之间的正式一步，生图前先审表。

## 画面构成（v2 修正）
不要只配一个珊瑚湾角色头像。
每句画面 = 地标 / 场景（珊瑚湾成熟扁平画风）+ 这句相关的物体（金钱等）+ 必要的图形符号（问号、打叉、打勾、箭头等）。
示例：第 1 句 = 深圳地标建筑 + 珊瑚湾画风 + 金钱元素 + 大问号。

## 素材匹配规则（置信度门槛）
- 优先匹配已经有的素材。
- 不要强制匹配。
- 置信度 >= 80%：复用已有素材。
- 置信度 < 80%：没有合适的，直接生成新图。

## 流程
文案 → 理解表（每句：原句、在讲什么、画面构成、英文提示词、不要画什么、风险点、匹配置信度、复用 / 新画）→ 用户审表 → 生图 / 复用渲染。
