# 参考视频制作方式分析：比奇堡学院《拿铁效应》

- 参考源：用户 2026-11-05 上传视频，209.5 秒、1280×720、30fps
- 分析依据：整段按秒抽帧 + 画面内容时序；1 秒一帧看不清 1 秒以内的入场缓动细节，入场时长只能定性为“快（<1 秒）”，不要把毫秒数当实测值
- 结论先说：背景已经过关，差距不在图片质量，而在“画面怎么摆、怎么进、怎么留、怎么接”

## 1. 排版：主体大、有落点、有分工，不是居中小卡

- 单人占画面高度约 35%–55%，双人各占约 30%–40% 宽度，并排站立，脚踩在同一条沙地线上。人物不是悬在画面中上部，而是有地面落点。
- 左右分工稳定：主角常固定在一侧，新增元素从另一侧进来，观众眼睛不用每句重新找主体。
- 画面分三层：背景海水、中间人物/道具、前景沙地水草。字幕在底部一层，价格和关键词在画面上方或物品上方，是另一层，不抢字幕位置。
- 容器固定：思考气泡是一个固定在左侧的大容器，里面的内容换（金币、存钱罐、50 元、愤怒表情），容器本身不动。我们的每句连容器一起换。
- 积累式排版：同一段里元素从左到右依次出现并保留，最后排成一排 3–4 个（零食摊、4 件小消费、奶茶/烤肠/包裹/VIP）。信息是加法，不是替换。
- 关键数字单独成屏：单价用金色大字 + 实物并排；合计用红色大字 + 背景整体虚化，数字是主角，人物退后或消失。

## 2. 动效：三种入场，没有统一浮动

- 水平滑入：第二个人、房子、账单、右侧道具从左右两侧快速滑进来，<1 秒到位。
- 放大弹出：金币、价格数字、气泡从小放大，带一点回弹感；气泡是从几个小圆点长成一朵大云，不是整张图直接出现。
- 虚化强调：关键词（拿铁效应、44 贝壳币、76 贝壳币）出现时，背景先虚化，红字再放大压在上面，段落感就是这么来的。
- 持续动作靠人物本身：表情和姿态换帧（笑、累、哭、得意），不是静态贴纸上下浮动。背景基本稳定，动的是前景元素。
- 对比我们现在：所有贴纸同一套——0.4 秒从上方掉 300px + 正弦上下浮动，幅度大、节奏全一样，看起来像贴纸在飘，而且浮动和语音、语义都没关系。

## 3. 切换：句内只换一个元素，段落才清屏

- 句内切换：背景和主角不动，只换或加一个元素（气泡内容、右手边新人物、手里的道具），切换点卡在分句和词语上，画面不闪。
- 句间切换：以硬切为主，但因为背景不变、主角位置可比，硬切不突兀。
- 段落切换：才用全屏变化——黑屏红字、背景虚化 + 大字、气泡框出现，相当于标点符号。
- 对比我们现在：每组是一个独立段，组内每句用 0.3 秒淡入，前一张到句末就消失，是“出现—消失—出现”，没有保留；标题和片尾又是黑底卡，和正片背景不连续。

## 4. 衔接：至少留一个锚点，道具要复用

- 锚点衔接：同一段里至少留一个元素跨句不动（主角、气泡、一排道具），转场时先留旧元素再进新元素，例如钱袋人物留着，气泡先生长出来。
- 语义衔接：画面讲因果链（挣钱→计划→存钱→花小钱→合计→超支），每个新元素是上一个的后果，不是孤立图标。
- 道具复用：金币、存钱罐、账单在全片反复出现，同一资产换姿态，观众不用每句重新认图。
- 数字模板固定：单价→实物→合计三步重复出现，到第三次观众就预期“红字合计要来了”，这是节奏感的来源。
- 对比我们现在：每句一个新图标，图标之间无复用、无因果、无留存，上一句一过就没了，观众每句都要重新认图。

## 5. 落到我们流水线的改造方向（未实施，等用户定）

- 布局：主道具/人物占画面高度 40%–50%，脚踩沙地线；双人左右分立；价格和关键词单独做一层大字，放在画面上方或物品上方。
- 动效：入场分三类——水平滑入、放大弹出、气泡生长；去掉统一大幅上下浮动，或改成极小呼吸（±5px 以内）。
- 切换：组内改成句内加法，上一句的元素保留到段落结束；只有段落切换时才清屏。
- 衔接：每段定一个锚点元素跨句保留；同一道具在全片复用，不每句画新图。
- 渲染实现：要改 make_cutout_from_script.py 的段结构，从“组 = 独立段、句末清除”改成“段 = 连续时间轴，元素各自有入场和出场时间”，用 ffmpeg overlay 的 enable 时间段 + x/y 表达式做滑入，用 scale 随时间变化做弹出。
