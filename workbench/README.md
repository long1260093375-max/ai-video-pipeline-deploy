# 科普视频工作台

v11 版式（背景 + 抠图贴纸）的本地工作台：选风格、选人物、选配音和字体，
输入选题 / 批量选题 / 自己的文案，生成视频，审片后导出。

## 启动

```bash
cd workbench
pip install -r requirements.txt   # 只需要 flask
python3 app.py
# 打开 http://127.0.0.1:5000
```

## Key（环境变量，只读，不进文件）

```bash
export ZHIPU_API_KEY=...        # 写稿 + 生图（智谱）必需
export DOUBAO_TTS_API_KEY=...   # 豆包配音；不设也可以跑，但配音可能失败
export ARK_API_KEY=...          # 预留（Seedream 一路以后接进来用）
```

页面顶上只显示“已设置 / 未设置”，绝不显示 Key 的值。某个 Key 缺失时，
对应的步骤会直接失败并写明原因，不会悄悄出一个没声音 / 没图的成片。
渲染后还会验音：配音平均音量低于 -60 dB 就判失败。

## 流程

1. 新建一集：选模板（默认 coral-bay）、人物（默认全选）、配音（默认熊二 1.1x）、
   字幕字体（默认思源黑体 SC Bold）。
2. 四种输入：单个选题（自动写稿）、批量选题（一行一个，最多 20 个）、
   自己的文案（粘贴后拆句，你改分句再确认）、已有脚本（重渲旧集，可换模板/配音/字体）。
3. 理解表：写稿后自动出一份草稿表（句 → 场景/物体/符号/生图提示词，
   按模板的 world_bible 规则生成，不调付费模型），你改完确认了才生图。
4. 生图：智谱 CogView-4 按理解表画主贴纸，再用 rembg U2Net 抠成透明 PNG。
   v1 只画主贴纸，不画细节小贴纸。
5. 渲染：调已有的 make_cutout_from_script.py（--template 模板名），
   版式、动效、飞机绕飞、字幕位置都沿用渲染器里的定版规则，工作台不重定。
6. 审片：看视频 + 口播稿，通过才能导出；批量导出是已通过的打一个 zip。

## 任务状态

`data/jobs.json` 存所有任务，`data/jobs/<id>/` 存每集的脚本、理解表、
贴纸、成片和日志。程序重启后，之前“进行中”的任务会标成“已中断”，
可以点重试。

## 已知限制（v1）

- 细节小贴纸（句中飞进来的第二张图）v1 不生成，渲染时不带 --details。
- 生图只用智谱 CogView-4；Seedream 一路还没接进工作台（还在走 Muse 的
  保险库，本地部署时再接 ARK_API_KEY）。
- 豆包配音走渲染器里现有的豆包 helper（Muse 保险库通道）；本地部署时
  改成读 DOUBAO_TTS_API_KEY。
- 字体选择通过 PIPELINE_FONT_PATH 环境变量传给渲染器（pipeline.py 里
  加了一行优先读这个变量的逻辑，默认行为不变）。
